# ⚡ Studio X

### Build powerful mobile & web apps with AI — no coding needed.

Studio X turns a plain-English idea into a real, running **Flutter** app. Describe what you want, and the AI plans the screens, generates the Dart code, wires up navigation and APIs, and gives you a live preview — then ships it to Android & iOS.

## ✨ Features

- 🧠 **AI App Builder** — describe your app in plain English; Studio X plans screens, models, and navigation, then generates production-ready Flutter/Dart code.
- 💬 **AI Chat Assistant** — an in-app assistant for Flutter, Dart, design, and Studio X help. Switch between **Claude** and **Gemini**.
- ✏️ **Live Edit Mode** — ask the assistant to change your app ("add a settings screen with dark mode") and watch it edit the code in real time.
- 👁️ **Instant Preview** — see your app render live in the browser as it's built, no emulator needed.
- 🎨 **Figma Import** — paste a Figma link and turn designs into Flutter UI.
- 🔌 **API Manager** — import your REST endpoints and let the AI generate connected, Dio-powered code.
- 🧩 **Templates & Components** — start from ready-made app templates and reusable components.
- 📱 **Android & iOS Builds** — one-click release builds, with over-the-air updates via **Shorebird**.
- 🖥️ **Local AI Engine** *(desktop)* — run an on-device model for 0-latency, private inference.
- 💳 **Credits & Usage** — transparent credit metering with a live 5-hour usage window.

## ⬇️ Download & Install (macOS)

1. Grab the latest **`.dmg`** from the [**Releases**](https://github.com/Aakashcs/StudioX-MacOS/releases/latest) page.
2. Open the `.dmg` and drag **Studio X** to **Applications**.
3. First launch: **right-click the app → Open** (the build isn't notarized yet, so macOS Gatekeeper asks once). After that it opens normally.

> Prefer no install? Use the web app at **[xstudio.website](https://xstudio.website)**.

---

## 🚀 Quick Start

1. Open Studio X (or the website) and **create an account**.
2. Click **Build the Impossible** and describe your app — e.g. *"A banking app with login, transfers, and transaction history."*
3. Watch Studio X plan the screens and generate the code.
4. Use **Chat** to refine anything, hit **Preview** to see it live, and **Build** to get an APK/IPA.
